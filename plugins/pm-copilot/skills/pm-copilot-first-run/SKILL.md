# PM Co-Pilot first run

Run the four PM Co-Pilot workflows once so the user can verify channels, people, tone, and level of detail before relying on the system.

Read `memory/role.md` and `memory/day-to-day.md` first. Use only connected tools and clearly note any skipped sources.

## Run order

Activate each workflow in this order, showing one result at a time:

1. `morning-brief`, for today
2. `weekly-prep`, as a start-of-week simulation
3. `open-loops`
4. `self-improvement`, using its light pass

Treat every result as a preview. Do not send messages, close items, update a task tracker, or make external changes during this calibration pass unless the user explicitly approves that specific action.

## Calibration checkpoint

After each workflow, ask briefly:

- Are these the right channels and people?
- Is the detail and tone right?
- Is anything here not actually theirs?

Apply only corrections the user confirms, and only to the relevant memory file. Use `memory/day-to-day.md` for tools and channels, `memory/colleagues.md` for people, and `memory/voice.md` for tone and detail.

## Close

Summarize what was correct and what was adjusted. Tell the user the system is calibrated and that they can invoke the individual workflows whenever needed from the workspace containing `AGENTS.md` and `memory/`.
